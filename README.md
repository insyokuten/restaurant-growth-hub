# 飲食店経営の右腕

個人・小規模飲食店の経営改善記事と無料ツールのサイトです。

## 初期セットアップ

1. Settings > Pages > Source: GitHub Actions
2. このフォルダの中身をリポジトリのルートに配置
3. Actionsでビルド成功を確認
4. `_config.yml` の `line_url` は実際の公式LINE URLが確認できてから設定

## 記事公開

`_posts/YYYY-MM-DD-slug.md` を追加すると記事一覧に表示されます。未承認の原稿は公開リポジトリに追加しないでください。公開前に必ず内容と出典を確認してください。

## 注意

初期サイトは記事ゼロで公開します。運営者情報、プライバシー文言、公式LINE URLは公開運用前に整備してください。GitHub Pagesの利用規約・制限を確認してください。

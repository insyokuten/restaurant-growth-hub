# 飲食店のABC分析のやり方｜売上構成比でメニューを見直す5つの手順

「メニューが増えて、どの商品から見直せばよいか分からない」。そんなときは、売上への貢献度を数字で整理すると、優先順位を決めやすくなります。

ABC分析を使えば、主力商品と見直し候補を一覧にできます。この記事では、売上構成比の計算からA・B・Cへの分類、改善策の選び方までを5つの手順で紹介します。

## 飲食店のABC分析とは？

ABC分析は、商品を売上などの指標が大きい順に並べ、累計構成比によってグループに分ける方法です。飲食店では、主力メニューの把握や品数の見直しに活用できます。

今回は売上高を基準にします。売上構成比は、対象商品の売上が分析対象全体の売上に占める割合です。

**売上構成比（％）＝商品別売上÷対象商品の売上合計×100**

累計構成比は、売上の大きい商品から構成比を順番に足した数字です。

## ABC分析のやり方：5つの手順

1. 分析する期間と商品群を決める。まずは直近1か月のフードなど、比較しやすい範囲を選びます。

2. POSレジや伝票から商品別の販売数と実際の売上を集計します。

3. 商品別売上を大きい順に並べ、売上構成比を計算します。

4. 上から構成比を足し、累計構成比を求めます。

5. 分類基準を決めてA・B・Cに分け、改善する商品を選びます。

## 計算例：5商品の売上を分類する

対象5商品の月間売上合計を20万円とします。

| 商品 | 月間売上 |
| --- | ---: |
| 唐揚げ | 80,000円 |
| パスタ | 60,000円 |
| サラダ | 30,000円 |
| ポテト | 20,000円 |
| デザート | 10,000円 |
| 合計 | 200,000円 |

唐揚げの構成比は80,000円÷200,000円×100＝40％です。パスタは30％なので、2商品までの累計は70％になります。

| 商品 | 構成比／累計 |
| --- | ---: |
| 唐揚げ | 40％／40％ |
| パスタ | 30％／70％ |
| サラダ | 15％／85％ |
| ポテト | 10％／95％ |
| デザート | 5％／100％ |

今回は累計75％以下をA、75％超95％以下をB、95％超をCとします。境界をまたぐ商品は、その商品を加えた後の累計値で分類するルールです。

| 分類 | 商品 |
| --- | --- |
| A | 唐揚げ・パスタ |
| B | サラダ・ポテト |
| C | デザート |

Aの2商品で対象売上の70％を占めています。分類基準は店舗の目的に合わせて設定できます。

## 分類ごとに何を改善する？

### A：主力商品の販売機会を守る

欠品や提供遅れが起きていないか確認します。売れ筋の仕込み量、食材の発注、調理手順を優先的に整えましょう。

### B：注文される機会を増やす

メニュー表の説明や写真、スタッフのおすすめ方法を見直します。例えばサラダを主菜と一緒に提案し、販売数や粗利益がどう変わるか記録します。

### C：残す理由と負担を確認する

販売数だけでなく、専用食材の廃棄、仕込み時間、常連客からの支持も確認します。他の商品と食材を共有できるなら、販売数が少なくても維持しやすい場合があります。

廃棄の記録方法は、[飲食店の食品ロスを減らす方法](https://insyokuten.github.io/restaurant-growth-hub/articles/doc-1mWpNuiyYIR__pdjFomeu-9H3z7GHnZ9E5cphHMho28A/)も参考にしてください。

## 売上ABCと粗利益ABCの違い

売上ABCは売上への貢献度を調べます。粗利益ABCでは、商品ごとの粗利益合計を大きい順に並べます。

例えば、売上8万円で売上原価4万円の商品と、売上6万円で売上原価1万5,000円の商品では、粗利益はそれぞれ4万円と4万5,000円です。売上順位と粗利益順位は逆になります。

売上ABCで主力商品を把握した後、粗利益も確認すると、販売促進と利益改善を両立しやすくなります。

## よくある質問

### ABC分析は毎月行うべき？

月次で同じ条件の分析を続けると変化を比較しやすくなります。季節商品や期間限定商品は販売期間もそろえて比較しましょう。

### Cランクの商品は削除したほうがよい？

削除の前に、粗利益、仕込み負担、食材共有、来店動機への影響を確認します。まずは提供曜日を限定するなど、小さく試す方法もあります。

## まとめ

ABC分析は、売上への貢献度からメニュー改善の順番を考える方法です。まずは直近1か月の売上を並べ、構成比と累計構成比を計算しましょう。

## 計算例と運用上の注意点

数値は説明用の試算で、実店舗の実績ではありません。分類基準は一例です。値引きや返品を反映した売上を使い、税込・税抜の集計方法を統一してください。対象商品群の構成比は店舗全体の構成比とは異なります。端数処理前の数値で累計を計算し、境界商品の扱いを毎回統一しましょう。

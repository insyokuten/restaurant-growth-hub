# 飲食店のキャッシュレス決済手数料はいくら？月間コストの計算と見直し方

「売上は増えているのに、カードやQR決済の手数料がどれくらいかかっているのか分からない」。そんなときは、決済方法ごとの利用額と料率を整理すると、毎月の負担を把握できます。

この記事では、決済手数料の計算方法、月額費用を含めた比較、契約を見直す手順を紹介します。

## 飲食店の決済手数料とは？

キャッシュレス決済を受け付ける店舗が、契約に基づいて負担する費用です。一般に決済額に一定の料率を掛けて計算します。料率は決済方法、ブランド、契約条件などによって異なります。

楽天ペイの[店舗向け解説](https://information.pay.rakuten.net/hc/ja/articles/15502487257615)でも、決済手数料以外に初期費用や月額費用などを含めて比較する考え方が紹介されています。

## 月間の決済手数料を計算する方法

**月間手数料＝対象決済額×契約料率**

月商200万円のうち60％がキャッシュレスで、実際に負担する料率を一律3％と仮定します。

| 項目 | 金額・割合 |
| --- | ---: |
| 月商（税込決済額） | 200万円 |
| キャッシュレス比率 | 60％ |
| 対象決済額 | 120万円 |
| 手数料率 | 3％ |
| 月間手数料 | 36,000円 |
| 年間手数料 | 432,000円 |

200万円×60％×3％＝36,000円です。年間は同じ条件が12か月続く場合の金額です。

## カードとQR決済で料率が違う場合

決済方法ごとに計算して合計します。

| 決済方法 | 月間手数料 |
| --- | ---: |
| カード80万円×3％ | 24,000円 |
| QR決済40万円×2％ | 8,000円 |
| 合計 | 32,000円 |

この例では、キャッシュレス決済額120万円に対する平均負担率は約2.67％です。

## 月額料金があるプランは損益分岐点で比較する

月額無料・料率3％のAプランと、月額3,000円・料率2.5％のBプランを比較します。その他の費用や対象ブランドは同じ条件とします。

**分岐点の決済額＝月額料金の差÷料率の差**

3,000円÷0.005＝60万円です。

| 月間対象決済額 | A／Bの費用 |
| --- | --- |
| 30万円 | 9,000円／10,500円 |
| 60万円 | 18,000円／18,000円 |
| 120万円 | 36,000円／33,000円 |

対象決済額が60万円を超えると、この条件ではBの方が安くなります。120万円なら月3,000円、年36,000円の差です。

店舗全体の固定費と必要売上については、[飲食店の損益分岐点の計算方法](https://insyokuten.github.io/restaurant-growth-hub/articles/doc-1XQiyA-mOjoV6YdDSvjth3svQmgvm2XayfpkwZWDrqAw/)も参考になります。

## 決済コストを見直す5つの手順

1. 直近3か月の決済明細を集め、カード・QR・電子マネー別の金額を確認する。

2. 契約料率、手数料にかかる税、月額料金、振込手数料を整理する。

3. 各プランの月間総費用を同じ決済額で計算する。

4. 入金日、対応ブランド、端末費用、解約条件、キャンペーン終了後の料金を比較する。

5. 変更後の明細で、想定した費用と実際の負担が一致するか確認する。

決済方法別に試算したい場合は、外部の[無料キャッシュレス決済計算ツール](https://foodbiz.bl-toolbox.jp/cashless/)も利用できます。

## 手数料だけでなく入金日も確認する

月末に売上が発生しても、入金が翌月なら、その間の仕入れや給与の支払いに使えません。契約を比較するときは、締め日、入金日、振込手数料も確認しましょう。

## まとめ

まずは月間のキャッシュレス決済額と実際の手数料を把握しましょう。料率だけでなく月額料金や入金条件を含めて比較すると、自店に合う契約を判断しやすくなります。

## 計算例と運用上の注意点

掲載数値は説明用のシミュレーションであり、実店舗の実績や特定サービスの料金ではありません。決済額は税込の取扱額を想定し、例示料率は実際の負担額を算出できる条件としています。手数料の課税関係、端数処理、返金、ブランド別条件は契約明細で確認してください。売上計上額と入金額は区別し、会計・税務処理は契約内容に応じて確認しましょう。カード手数料の顧客への上乗せなどは加盟店規約に抵触する場合があるため、規約を確認してください。

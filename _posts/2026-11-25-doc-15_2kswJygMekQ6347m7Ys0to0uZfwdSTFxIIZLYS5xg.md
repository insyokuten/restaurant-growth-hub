# 飲食店の人時売上高とは？計算方法とスタッフ配置の改善手順

「忙しい時間はスタッフが足りないのに、暇な時間は人が余っている」。そんな悩みを整理するのに役立つ数字が、人時売上高です。

人時売上高を時間帯ごとに確認すると、スタッフを増やしたい時間や、仕込み・清掃の時間を見直したい時間が見えてきます。この記事では、計算方法から自店の目標設定、シフト改善までを紹介します。

## 人時売上高とは？

人時売上高（にんじうりあげだか）は、店舗で働く人1人が1時間あたりに生み出す売上を表す指標です。

**人時売上高＝売上高÷総労働時間**

総労働時間は、同じ期間に働いた全員の実際の労働時間の合計です。3人がそれぞれ5時間働けば15時間になります。店舗全体の効率を見る場合は店主の作業時間も含めましょう。

## 人時売上高の計算例

1日の税抜売上が12万円、総労働時間が30時間の場合を考えます。

| 項目 | 数値 |
| --- | ---: |
| 売上 | 120,000円 |
| 総労働時間 | 30時間 |
| 人時売上高 | 4,000円 |

120,000円÷30時間＝4,000円です。

同じ売上を維持できる条件で、業務の見直しによって総労働時間が変わると、次のようになります。

| 総労働時間 | 人時売上高 |
| --- | ---: |
| 30時間 | 4,000円 |
| 27時間 | 約4,444円 |
| 24時間 | 5,000円 |

## 人時売上高の目安はどう決める？

自店の人件費予算から目標を逆算する方法があります。ここでは、集計対象の労働時間1時間あたりの平均人件費を1,200円、目標人件費率を30％と仮定します。

**目標人時売上高＝平均時間あたり人件費÷目標人件費率（小数）**

1,200円÷0.30＝4,000円です。

売上予測が12万円なら、予算上の総労働時間は120,000円÷4,000円＝30時間となります。この時間を基準に、予約状況や必要な作業量を考えてシフトを組みます。平均人件費と人件費率の集計範囲はそろえてください。

## 時間帯別に見ると改善箇所が分かる

例えば、営業時間と開閉店作業を次のように分けて記録します。

| 時間帯 | 売上／総労働時間 |
| --- | --- |
| 開店準備 | 0円／3時間 |
| ランチ | 60,000円／10時間 |
| 午後 | 10,000円／5時間 |
| ディナー | 50,000円／10時間 |
| 閉店作業 | 0円／2時間 |

ランチは6,000円、午後は2,000円、ディナーは5,000円です。午後に手が空く時間があるなら、夕方の仕込みを午後に移せるか検討します。開店準備や閉店作業は売上がなくても必要な仕事なので、作業内容と所要時間で評価しましょう。

## スタッフ配置を改善する5つの手順

1. POSレジや売上帳から時間帯別の売上を集計する。

2. 勤怠記録から休憩を除いた実労働時間を集計する。

3. 時間帯別の人時売上高を計算し、予約状況や提供待ち時間と照らし合わせる。

4. 仕込みの集約、動線改善、作業分担の変更など、負担を減らす方法を試す。

5. 同じ曜日の変更前後を比較し、売上、利益、提供時間、残業の変化を確認する。

## 人時生産性・人件費率との違い

人時売上高は売上を基準にします。一方、ここでいう人時生産性は粗利益を基準にします。

**人時生産性＝粗利益（売上－売上原価）÷総労働時間**

売上12万円、売上原価4万円、総労働時間30時間なら、人時生産性は約2,667円です。

人件費率は売上のうち人件費が占める割合です。これらを組み合わせると、売上効率と利益、費用の関係を確認できます。

固定費も含めて必要な売上を確認するには、[飲食店の損益分岐点の計算方法](https://insyokuten.github.io/restaurant-growth-hub/articles/doc-1XQiyA-mOjoV6YdDSvjth3svQmgvm2XayfpkwZWDrqAw/)も参考にしてください。

## まとめ

まずは1週間、売上と総労働時間を記録しましょう。人時売上高を時間帯別に見ることで、忙しい時間への人員配置や作業分担を検討しやすくなります。

自店の売上や人件費から改善の優先順位を整理したい方は、[公式LINEの無料売上改善AI診断](https://s.lmes.jp/landing-qr/2011246046-wwYg1mao?uLand=HYND0b)をご活用ください。

## 計算例と運用上の注意点

掲載数値は説明用のシミュレーションです。業界平均や実店舗の改善実績ではありません。金額は税抜売上で統一しています。目標値は業態や原価率、営業時間、接客方針に応じて設定してください。必要な休憩や実労働時間を削除したり、無給の作業に置き換えたりせず、サービス品質とスタッフの負担も確認しましょう。時間帯別の数値は仕込みと販売の時間差にも影響されます。

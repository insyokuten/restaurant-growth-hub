# 飲食店の棚卸しのやり方｜月末の在庫確認と原価率の計算手順

「毎月仕入れは確認しているけれど、食材がどれだけ残っているか分からない」。そんなときに役立つのが**棚卸し**です。

月末の在庫を数えて金額にすると、その月に使った食材の原価をより正確に把握でき、発注量やメニュー価格の見直しにもつなげられます。この記事では、小規模飲食店向けに**数え方・記録方法・原価率の計算**を順番に紹介します。

## 棚卸しとは？ 何のために行う？

棚卸しとは、決めた日時に残っている食材・飲料などを実際に確認し、数量と金額を記録する作業です。

仕入れた食材がすべてその月に使われるとは限りません。月末に残った分を把握することで、仕入額と実際の原価の違いを確認できます。

## まずは棚卸し表に記録する項目を決める

最初は次の項目があれば始められます。

| 記録項目 | 記入例 |
| :--- | ---: |
| 品名 | 米 |
| 単位 | kg |
| 残量 | 8 |
| 評価単価 | 400円 |
| 在庫金額 | 3,200円 |

**在庫金額＝残量×評価単価**です。表の金額は説明用の仮定です。

単位は「袋」「本」「kg」など品目ごとに統一します。例えば米をkgで数えるなら、単価も1kg当たりにそろえます。開封済みの調味料やボトル類は、残量を測る方法を決めておきましょう。

## 月末の棚卸しを進める5つの手順

1. **数える日時を決める。** 月末の営業終了後など、入出庫が少ない時間に統一します。

2. **保管場所ごとに一覧を作る。** 冷蔵庫・冷凍庫・乾物棚・ドリンク棚など、数え漏れを防げる順番に並べます。

3. **現物を数えて残量を記録する。** 未開封品と開封済み品を区別し、記録単位をそろえます。

4. **数量を金額に換算する。** 採用している在庫評価方法に沿った単価を使い、品目ごとの在庫金額を合計します。

5. **前月末と今月末を比較する。** 在庫の増減、使い切れていない食材、発注量の偏りを確認します。

棚卸し表は毎月同じ順番・同じ単位で使うと、担当者が変わっても比較しやすくなります。

## 棚卸しから食材原価と原価率を計算する

月の食材原価は、基本的に次の式で求めます。

**食材原価＝月初在庫＋当月仕入−月末在庫**

例として、すべて税抜で次の数字を仮定します。

- 月初在庫：10万円
- 当月仕入：60万円
- 月末在庫：15万円
- 当月売上：200万円

食材原価は、10万円＋60万円−15万円＝**55万円**です。

**原価率＝食材原価÷売上×100**

55万円÷200万円×100＝**27.5％**となります。

仕入額60万円だけで計算すると30％になりますが、在庫の増加5万円を考慮すると27.5％です。数字の違いを理解すると、仕入れすぎと原価の上昇を区別しやすくなります。

## 原価率が上がったら確認したいこと

月末在庫を確定したら、次の順番で確認します。

1. 数え漏れや数量単位の間違いがないか確認する。

2. 仕入単価が前月から上がっていないか確認する。

3. 廃棄・まかない・試作品などの使用記録を確認する。

4. 売れたメニューの構成や盛り付け量に変化がないか確認する。

5. 必要に応じて発注量・仕込み量・価格を見直す。

原価率の数字だけで原因を決めつけず、**数量・単価・廃棄記録**を合わせて見ることが重要です。

## 計算例と運用上の注意点

この記事の金額は説明用の仮定であり、実在店舗の実績・業界平均ではありません。原価率の計算では売上と原価の税込・税抜の基準をそろえてください。廃棄による減少が棚卸し後の原価に含まれている場合、廃棄額を重複加算しないよう注意が必要です。

税務申告に用いる棚卸資産の評価方法は、事業者が選択・適用する方法や税務上のルールに従います。決算時の評価方法や処理については税理士・税務署に確認してください。

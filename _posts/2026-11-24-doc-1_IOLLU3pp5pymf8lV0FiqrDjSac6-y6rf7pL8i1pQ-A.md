# 飲食店の値上げで客離れは何人まで許容できる？利益を守る計算方法

「食材費が上がっているので値上げしたい。でも、お客様が減るのが心配」。そんなときは、値上げ後に必要な客数を先に計算しておくと、価格改定の判断基準を持てます。

この記事では、居酒屋やカフェなどの小規模飲食店を想定し、現在の利益を維持するために必要な客数と、値上げ後に確認したい数字を紹介します。

## 値上げの判断は売上よりも利益に注目する

売上から、お客様の人数に応じて増減する費用を引いた金額を「限界利益」と呼びます。食材費や消耗品費、決済手数料などが変動費の例です。

**1人あたりの限界利益＝客単価－1人あたりの変動費**

月間の限界利益から家賃などの固定費を引くと、このモデルでの営業利益を計算できます。

## 100円の値上げで何人まで客数が減っても利益を維持できる？

月間客数800人、客単価2,500円、1人あたりの変動費900円、月間固定費100万円の店舗を想定します。値上げによって平均客単価が100円上がり、1人あたりの変動費と固定費は変わらない条件です。

| 項目 | 値上げ前 |
| --- | ---: |
| 月間客数 | 800人 |
| 客単価 | 2,500円 |
| 1人あたり変動費 | 900円 |
| 月間限界利益 | 128万円 |
| 月間営業利益 | 28万円 |

値上げ後の1人あたりの限界利益は、2,600円－900円＝1,700円です。

**利益維持に必要な客数＝値上げ前の月間限界利益÷値上げ後の1人あたり限界利益**

128万円÷1,700円＝約752.94人。人数は切り上げて753人です。

つまり、800人から47人減るまで（約5.9％減）なら、計算上は現在の利益を維持できます。

## 客数の減少幅別に利益を比較する

| 値上げ後の客数 | 月間営業利益 |
| --- | ---: |
| 800人（減少なし） | 36万円 |
| 776人（3％減） | 31万9,200円 |
| 760人（5％減） | 29万2,000円 |
| 753人（約5.9％減） | 28万100円 |
| 720人（10％減） | 22万4,000円 |

値上げ前の利益は28万円です。客数が5％減る条件では利益が1万2,000円増え、10％減る条件では5万6,000円減ります。

また、760人の場合の売上は197万6,000円で、値上げ前の200万円より少なくなります。それでも利益は増える計算です。売上と利益を分けて確認することが大切です。

## 食材費も上がる場合はどう計算する？

1人あたりの変動費が900円から950円に増える場合、値上げ後の限界利益は2,600円－950円＝1,650円です。

128万円÷1,650円＝約775.76人。以前の利益を維持するには776人以上が必要になります。

この場合、客数の減少は24人（3％）までが利益維持の目安です。価格改定と同時に費用が変わる場合は、新しい費用で計算しましょう。

## 値上げ前後に行う5つの手順

1. 直近の客数、客単価、変動費、固定費を集計する。

2. 価格改定後の平均客単価を、各商品の販売数を参考に見積もる。

3. 客数が変わらない場合、3％減る場合、5％減る場合、10％減る場合の利益を試算する。

4. 原価や注文数を参考に、価格を見直す商品を選び、変更内容をお客様に分かりやすく伝える。

5. 改定後は週ごとに客数、客単価、商品別注文数、限界利益を記録する。

曜日や営業時間が近い期間を比較すると、変化を把握しやすくなります。

## よくある質問

### すべての商品を100円値上げすれば客単価も100円上がる？

客単価の変化は注文数や商品の組み合わせで変わります。例えば、1人が値上げ対象商品を平均2品注文する場合と、対象商品を注文しない場合では影響が異なります。実際の平均客単価を確認しましょう。

### 赤字にならない客数も計算できる？

固定費を1人あたりの限界利益で割れば、このモデルで赤字を回避するための必要客数を計算できます。今回の「現在の利益を維持する客数」とは異なる指標です。

詳しくは[飲食店の損益分岐点の計算方法](https://insyokuten.github.io/restaurant-growth-hub/articles/doc-1XQiyA-mOjoV6YdDSvjth3svQmgvm2XayfpkwZWDrqAw/)をご覧ください。

## まとめ

値上げを検討するときは、現在の利益と値上げ後の1人あたりの限界利益を計算し、必要な客数を把握しましょう。価格を変更した後も、客数だけでなく利益の変化を確認することが重要です。

## 計算例と運用上の注意点

掲載数値は説明用のシミュレーションです。客数減少率を予測したものではありません。金額は税抜で統一しています。固定費や注文構成、決済手数料などが変化する場合は再計算してください。季節や天候、競合店の状況も客数に影響するため、値上げ前後の差をすべて価格改定の影響とみなさないようにしましょう。

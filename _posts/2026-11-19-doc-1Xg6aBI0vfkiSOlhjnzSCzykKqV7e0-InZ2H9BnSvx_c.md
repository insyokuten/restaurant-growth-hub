# 飲食店の資金繰り表の作り方｜売上があっても現金が足りない原因と対策

「売上はあるのに、月末の支払いが心配」。そんなときは、**売上が発生する日と、実際にお金が入る日**を分けて整理すると、資金不足を早めに予測できます。

この記事では、個人経営の居酒屋・カフェ・バーなどに向けて、**資金繰り表の基本、記入例、毎週の確認手順**を分かりやすく紹介します。

## 資金繰り表とは？ 利益と現金の違い

資金繰り表は、一定期間にいつ・いくら現金が入って、いつ・いくら出ていくかを整理する表です。

まずは3つの言葉を区別しましょう。

- **売上**：料理やドリンクを販売した金額
- **利益**：売上から費用を差し引いた金額
- **資金残高**：その時点で支払いに使える現金・預金の残り

例えばカード決済の売上が今月発生しても、入金が翌月なら、今月の支払いに使えるお金はまだ増えません。資金繰り表では**実際の入出金日**を基準に記録します。

## まずは5項目で作る

1. **月初残高**：月初に使える現金・預金

2. **当月入金**：現金売上、カード・QR決済の入金など

3. **当月支出**：仕入れ、給与、家賃、光熱費、税金、借入返済など

4. **当月収支**：当月入金 − 当月支出

5. **月末予測残高**：月初残高 ＋ 当月収支

この5項目を月ごとに並べるだけでも、資金の流れが見え始めます。

## 資金繰り表の記入例

次は説明用の仮定です。単位は万円です。

| 項目 | 金額（万円） |
|:--|--:|
| 月初残高 | 80 |
| 現金売上の入金 | ＋70 |
| キャッシュレス決済の入金 | ＋90 |
| 仕入れの支払い | −55 |
| 人件費の支払い | −60 |
| 家賃・光熱費など | −30 |
| 借入金元本の返済 | −10 |
| **月末予測残高** | **85** |

計算は**80＋70＋90−55−60−30−10＝85万円**です。

この例では月末に85万円が残る見込みです。月末の数字だけでなく、**給与日や家賃支払日の直前にいくら残るか**も確認しましょう。

## 月末だけでなく週ごとの残高を確認する

月末残高がプラスでも、月の途中に大きな支払いが集中することがあります。

- 第1週：月初残高と入金予定を確認
- 第2週：仕入れ・家賃などの支払日を確認
- 第3週：キャッシュレス決済の入金日を確認
- 第4週：給与・返済・税金の支払日を確認

週ごとに「前週末残高＋今週の入金−今週の支出」を計算して、残高が最も少なくなる時期を探します。

## 飲食店で見落としやすい4つの項目

### 1. キャッシュレス決済の入金日

カード・QR決済は契約によって入金日や手数料が異なります。売上日ではなく、実際の入金予定日と入金予定額で管理します。

### 2. 仕入れの締め日と支払日

食材を仕入れた日と代金を支払う日は一致しない場合があります。仕入先ごとの請求書・支払期限を一覧にしましょう。

### 3. 税金・社会保険料

毎月同額とは限らない支払いも、納付予定月に記入します。未確定の金額は見込み額として区別して管理します。

### 4. 借入金の元本返済

借入元本の返済は、一般に損益計算書の費用とは別に扱われますが、現金は出ていきます。資金繰り表には予定返済額を含めましょう。

## 毎週15分の更新手順

1. 通帳や決済サービスで入金履歴と入金予定を確認する

2. 仕入先の請求書と支払期限を確認する

3. 給与・家賃・返済・税金の予定を入力する

4. 今週末と翌週末の予測残高を計算する

5. 残高が少ない週を見つけ、支出や入金の予定を再確認する

予測と実績がずれたら、金額だけでなく入金日・支払日がずれた理由も残しましょう。

## 資金不足が予想されるときは

まず、入金予定の漏れや請求書の二重計上がないか確認します。そのうえで過剰在庫や発注量、固定費など見直せる支出を整理します。支払いが難しくなる見込みがある場合は、期限直前まで放置せず、税理士や金融機関などへ早めに相談しましょう。

## よくある質問

### 黒字なら資金繰り表は不要ですか？

黒字でも入金より支払いが先行すれば現金が不足する場合があります。利益管理と資金繰り管理は別々に確認する必要があります。

### 毎日作成する必要がありますか？

まずは週1回の更新から始められます。支払いが集中する日や残高が少ない時期は、日単位で確認しましょう。

## まとめ

資金繰り表は、**月初残高＋入金予定−支払予定＝月末予測残高**を基本に作れます。

カード決済の入金日と、給与・家賃・仕入れなどの支払日を整理し、週ごとの予測残高を更新することから始めましょう。

## 計算例と運用上の注意点

上記の金額はすべて説明用の仮定であり、実店舗の実績や業界平均ではありません。実際には税金、保険料、設備購入、店主の生活費への引き出し、決済手数料など、自店で発生する入出金を漏れなく記入してください。口座間の資金移動を重複計上しないよう注意し、対象とする現金・預金の範囲を統一してください。資金繰り表は予測であり、資金残高と利益は一致しません。

# 飲食店の月間売上目標の立て方｜平日・週末に分けて無理のない営業計画を作る

「来月の売上目標を決めたいけれど、毎日いくら売ればよいか分からない」。そんなときは、月間目標を平日と週末の営業計画に分けると、必要な客数や取り組むべき集客施策が見えてきます。

この記事では、小規模飲食店でも実践できる売上目標の計算方法と、毎週の進捗確認の手順を紹介します。

## 月間売上目標は客数と客単価から考える

**月間売上＝営業日ごとの客数×客単価の合計**

客単価とは、お客様1人あたりの平均売上です。月商の目標だけでなく、実際に何人のお客様を迎える必要があるかまで考えましょう。

まず前月の売上、客数、営業日数を確認し、平日と週末それぞれの1日平均客数と客単価を求めます。

## 平日と週末に分けて売上を予測する

客単価3,000円、25日営業する店舗の計画例です。平日17日、週末8日として計算します。

| 項目 | 売上計画 |
| --- | ---: |
| 平日1日（20人） | 6万円 |
| 週末1日（30人） | 9万円 |
| 平日17日 | 102万円 |
| 週末8日 | 72万円 |
| 月間合計 | **174万円** |

月間客数は20人×17日＋30人×8日＝580人です。

毎日同じ売上を目標にするより、曜日ごとの来店傾向に合わせて計画を立てることで、日々の営業判断に活用できます。

## 月商180万円を目指すなら何人必要？

月商174万円の計画に対して、180万円を目指す場合の差額は6万円です。

**追加で必要な客数＝60,000円÷3,000円＝20人**

例えば、平日17日のうち10日で2人ずつ追加できれば、月間20人の増加になります。

客数だけでなく客単価を見直す方法もあります。580人の来店を維持する場合、180万円÷580人＝約3,104円が必要な平均客単価です。

## 利益から売上目標を決める

売上目標は、店舗の費用を賄い、必要な利益を残せる水準からも考えましょう。

固定費90万円、変動費率40％、目標利益18万円の場合、必要売上は（90万円＋18万円）÷0.60＝180万円です。

詳しい計算方法は、[飲食店の損益分岐点の計算方法｜赤字にならない売上と必要客数](https://insyokuten.github.io/restaurant-growth-hub/articles/doc-1XQiyA-mOjoV6YdDSvjth3svQmgvm2XayfpkwZWDrqAw/)で解説しています。

## 営業計画を作る5つの手順

1. 翌月の営業日と休業日をカレンダーに記入する。

2. 過去の実績から平日・週末の平均客数と客単価を計算する。

3. 営業日ごとの売上目標を設定し、月間合計を求める。

4. 必要な利益から求めた売上目標との差を確認する。

5. 差を埋める具体策を決め、週ごとに実績を確認する。

例えば平日の客数を増やしたい場合は、空席の多い時間帯の告知や既存のお客様への再来店案内を検討します。客単価を上げたい場合は、追加注文しやすいメニューやおすすめの伝え方を見直します。

## 毎週の進捗を確認する方法

月の途中では、その日までの計画累計と実績累計を比較します。

例えば10営業日終了時点で計画70万円、実績65万円なら、差額は5万円です。残り15営業日で補う場合、当初の計画に1日平均約3,334円を追加する必要があります。

売上だけでなく客数と客単価のどちらが計画を下回ったかを確認すると、次に取り組む施策を選びやすくなります。

## まとめ

月間売上目標は、必要利益から計算した目標と、営業日別の客数・客単価から積み上げた計画を比較して決めましょう。まずは来月の営業カレンダーを作り、曜日別の目標を書き込むことから始めてください。

## 計算例と運用上の注意点

数値は説明用の仮定です。客数や客単価の増加を保証するものではありません。祝日、季節、予約状況、席数、スタッフの配置、追加費用を考慮し、実行可能な営業計画に調整してください。売上と費用は税込・税抜の基準をそろえて計算しましょう。

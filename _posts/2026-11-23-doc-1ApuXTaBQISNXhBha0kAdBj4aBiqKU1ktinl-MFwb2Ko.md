# 飲食店のドリンク原価率の計算方法｜1杯あたりの利益と価格設定の考え方

「ドリンクは利益が出やすいと聞くけれど、実際に1杯でいくら残っているか分からない」。そんなときは、提供する量と材料費を1杯ずつ計算すると、価格の見直しや仕入れ管理の改善点が見えてきます。

この記事では、居酒屋やバー、カフェなどの小規模飲食店向けに、ドリンク原価率の求め方、価格設定の考え方、ロスを減らす手順を解説します。

## ドリンク原価率とは？

**ドリンク原価率＝1杯の材料原価÷1杯の販売価格×100**

材料原価とは、ドリンク1杯を作るために使う飲料・割材・果物などの仕入れ費用です。原価率が25％なら、販売価格の25％が材料費に相当します。

比較するときは、材料費と販売価格をともに税抜でそろえましょう。

## 1杯の原価を計算する方法

例えば、700mL入りの酒類を税抜1,400円で仕入れ、1杯に45mL使う場合を考えます。

**酒類の原価＝1,400円÷700mL×45mL＝90円**

ここに割材40円、レモン10円を加えると、材料原価は140円です。

| 費用の内訳 | 1杯あたり |
| --- | ---: |
| 酒類45mL | 90円 |
| 割材 | 40円 |
| レモン | 10円 |
| 材料原価合計 | **140円** |

販売価格が税抜560円なら、原価率は140円÷560円×100＝**25％**。材料原価を引いた粗利益は420円です。

この粗利益から人件費、家賃、光熱費などを賄う必要があります。

## 目標原価率から販売価格を逆算する

**必要販売価格＝1杯の材料原価÷目標原価率**

材料原価140円で目標原価率28％とするなら、140円÷0.28＝税抜500円です。

目標原価率は店舗全体の費用や利益計画を踏まえて決めます。すべてのドリンクを同じ原価率にする必要はありません。

## 原価率だけでなく粗利益額を見る

次の2杯は原価率が違っても、粗利益額は同じです。

| 商品 | 粗利益 |
| --- | ---: |
| A：売価500円・原価100円 | 400円 |
| B：売価800円・原価400円 | 400円 |

Aの原価率は20％、Bは50％です。商品ごとの販売数、調理・提供の手間、客層との相性も合わせて評価しましょう。

店舗全体で必要な売上を考える際は、[飲食店の損益分岐点の計算方法](https://insyokuten.github.io/restaurant-growth-hub/articles/doc-1XQiyA-mOjoV6YdDSvjth3svQmgvm2XayfpkwZWDrqAw/)も参考になります。

## ドリンク原価を管理する5つの手順

1. 主要ドリンクの仕入れ価格と容量を記録する。

2. 1杯に使う酒類、割材、トッピングの量を決める。

3. 各材料の使用量から1杯の材料原価を計算する。

4. 税抜販売価格と比較し、原価率と粗利益額を確認する。

5. 月に一度、仕入れ値や実際の使用量を見直す。

計量カップやメジャーカップを使って注ぐ量をそろえると、品質の安定と原価管理を両立しやすくなります。

## 価格を見直すときのチェックポイント

仕入れ価格が上がった場合は、すぐに値上げを決めるのではなく、提供量、割材、メニュー構成、注文される頻度を確認します。

例えば原価140円、税抜売価560円のドリンクで材料原価が160円に上がると、原価率は約28.6％、粗利益は400円になります。

変更前後の数字を把握したうえで、販売価格や提供方法を検討しましょう。

## まとめ

ドリンク原価率は、仕入れ価格だけでなく1杯に使う量を決めることで計算できます。まずは売れ筋の3商品から原価率と粗利益額を調べ、価格と提供方法を見直してみましょう。

## 計算例と運用上の注意点

この記事の金額はすべて説明用の仮定であり、実店舗の実績ではありません。原価率の目標値は業態や立地、サービス内容で変わります。廃棄、試飲、注ぎ過ぎなどのロスが発生すると実際の原価は増えるため、棚卸しや仕入れ実績も確認してください。消費税の扱いをそろえ、飲食店の利益を判断する際は人件費などの経費も含めて検討しましょう。
